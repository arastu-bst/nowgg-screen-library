# now.gg — Decisions
Last updated: 2026-06-04 (session 4 audit)

> Design decisions with reasoning. Promoted from `scratchpad.md` at audit passes.

| Date | Decision | Why |
|---|---|---|
| 2026-06-02 | Token system reverse-engineered from the **live now.gg site** via computed-style extraction (not from Figma/source). | now.gg is live; no design-source file exists. Extraction captures the real rendered values; flagged extracted-vs-synthesized for honesty. |
| 2026-06-02 | Build as a **design-only replica** (mock catalog, no streaming/backend). | Same handoff philosophy as WSUP — fidelity + handoff clarity over a working product. |
| 2026-06-02 | now.gg gets its **own taste notebook**, separate from WSUP. | now.gg's design language (full-color art, dense grids, marketing surfaces) is unrelated to WSUP's slim companion aesthetic — sharing would contaminate both. |

| 2026-06-03 | The play page is the cloud-game **PLAYER**, not an info/marketing page; ONE slug-aware page opens for any game. | Design handoff — no per-game pages; the player is the experience. |
| 2026-06-03 | The player canvas is an **interactive 3-state flow**: launch (video + Play CTA, no bottom bar) → ad (pink loader + "will launch after the ad" gradient bar) → playing (control bar). | Matches live now.gg behavior; demonstrates all states in a static handoff via a client state machine. |
| 2026-06-03 | Player ad units: **2× 336×280 Large Rectangle** (side) + **728×90 Leaderboard** (under canvas), square-cornered, real creatives where supplied. | Real IAB units measured from the live DOM (slot, not inner iframe). |
| 2026-06-03 | Foundation is the **FLOAT design system**, extracted live from Figma (apmb9PRrJYKc7cNhCUgz7L) → design-source/figma/design-system/. Tokens folded into tailwind ADDITIVELY (legacy names preserved). | Authoritative source replaces reverse-engineered guesses; one shared foundation with WSUP. |
| 2026-06-03 | Installed the full now.gg icon library (419 SVGs, 4 sizes) and render via a **CSS-mask `Icon` component** (currentColor). | Library SVGs ship baked fills; masking themes them to any context. Hand-drawn kept only where no library equiv (star, chevron) or brand marks. |
| 2026-06-03 | Built a **/style-guide** route as the living handoff reference (colors, type, spacing/radius/elevation, icon library, components). | Phase 2 — single source for the system the designer hands off. |

| 2026-06-03 | **Token-audit pass** — migrated all raw values in the app code to tokens: white/black opacity → Float named translucents (`white-10`…`black-90`, off-scale snapped to the decade ramp), gradient/brand hex → tokens (`brand.youtube/discord`, `fill.bar`, `bg-player-bar`/`ad-loader`/`ad-launch-bar`, tooltip → `surface-raised`), `max-w-[1320px]` → `maxWidth.content`, snappable radii → scale (`rounded-xs`/`rounded-l`). | Match WSUP's "everything tokenized" bar. Build green + visuals identical. Genuine one-offs kept + documented: IAB ad sizes (336×280 / 728×90), ring-offset radii (card+1px), the 132px Figma icon, container `min-h`. |

| 2026-06-03 | **Patterns-kit extracted** — 14 recurring compositions documented in `design-source/figma/design-system/PATTERNS.md` + rendered live at `/style-guide` → Patterns (`PatternsSection`). | Closes the last delta vs WSUP — now.gg now has tokens + components + **patterns** + icons, under the same shared VDA gates/health-check. |

| 2026-06-03 | Player is a client **state machine**: launch → ad → loading → playing. Loading uses the cyan→purple "Widget Bar" (Figma 5319:20752); playing shows a real game-screen image; control bar is solid black with 40px-tap / 24px-white icons + rectangular (never-pill) buttons. | Matches the live now.gg player flow + the Figma; design-only (no real stream). |
| 2026-06-03 | **Glass popups**: `white-20` frosted panel (backdrop-blur) + **ALWAYS `black-70` scrim**; panel must frost the game (dim via scrim, not a fill behind the blur); inputs use the Float `Forms` states (default white-50 → hover white-70 → focus accent). | Designer-settled glass treatment; the Float pull has a `Forms` collection that must drive input states. |
| 2026-06-03 | Help icon opens **`RunDiagnosticModal`** (idle → running 18-check loader → done summary → "Report sent" confirmation). **`HelpSupportModal` kept** in /style-guide Patterns for future use. | Diagnostic-first support flow; preserve the form popup as a documented pattern. |

| 2026-06-04 | Play-page Popular Games wrapper `pt-10` → `py-10` — the full-bleed FeaturedBand gets the same 40px section rhythm above as below. | The section wrapper owns page rhythm; the band's internal `py-12` is content padding inside its colored surface, not page spacing. Alternative (margin on the band itself) rejected — bands are reusable full-bleed surfaces; rhythm belongs to the page wrappers around them. (Designer caught — Gate 8 miss.) |
| 2026-06-04 | Breadcrumb lives INSIDE the footer as its first row — `Footer` takes an optional `breadcrumb` prop (24px above the link columns); `Breadcrumb` renders only the trail, the container owns placement. | Live DOM measured (`design-source/measure-breadcrumb.js`): the trail `<ul>` is a child of `<footer>` (pad 40/20), not a page-body element above it. Alternative (standalone above the footer — the prior build) contradicted the live anatomy. (Designer caught the anatomy; resolved by measuring live BEFORE editing — same recurring category as S1–S3: verify the authoritative source.) |

| 2026-06-04 | `rail` spacing token fixed 72px → **70px** (live-measured) and WIRED: PlayerRail now uses `w-rail`/`size-rail` instead of `w-[70px]`/`size-[70px]`. | The token existed for exactly this dim but was dead (0 usages) and wrong (72 ≠ 70 live). A structural token must be used by its consumer or it silently drifts from the truth it encodes. Found by VDA grep during the "every little thing" audit — should have been caught at S3's token audit. |
| 2026-06-04 | Spacing convention documented in config + /style-guide → Scales: **classNames use the Tailwind numeric scale** (gap-3 = s/12, mb-6 = xl/24, py-10 = xxxl/40); named Float steps are the design-side handoff reference. | Audit measured 0 named-step className usages vs 135 numeric — the convention was real but unwritten; an undocumented dual scale invites drift in both directions. Alternatives: migrate 135 usages to named (huge churn, no visual gain) or delete the named scale (loses the Float handoff reference) — both rejected. |
| 2026-06-04 | Style-guide Breadcrumb pattern renders the REAL `Breadcrumb` component (enabled by the trail-only refactor) instead of an inline mockup. | The mockup had already drifted (3 crumbs vs the real 4-crumb trail). Live components in the guide can't drift from the implementation; prefer them over mockups wherever the component is placement-free. |

| 2026-06-04 | TopBar logo wrapped in `Link href="/"` (aria-label "now.gg home"). | Logo→home is the universal web convention and live now.gg does it; a logo that looks tappable but does nothing fails the connectivity check ("if a user taps this, what happens?"). Designer caught — should have been caught at the S2 TopBar build. Related open scope call: header avatar + Ana widget are still non-interactive (live opens menus/panels) — designer to decide if they stay design-only. |
